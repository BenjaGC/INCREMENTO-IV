## Ubicación del sistema

- Vistas: public/index.html, public/increment3-panel.html, public/css y public/js.
- Controladores/rutas: src/server.js, src/increment3.js, src/increment4/index.js y src/increment4/login-security.js.
- Servicios: src/increment4/trace-retention.js y módulos de src.
- Base final SQL: database/DDL.sql y database/DML.sql.
- Instalación: README.md y docs/INSTALACION.md.

El backend usa Express con rutas y servicios modulares; no existe una carpeta llamada controllers. La implementación del control está en los archivos indicados. No se cambia esa arquitectura para la entrega.

No se incluyen secretos ni datos operativos. Los currículums del Documento 0 se conservan para entrega privada; no forman parte de la publicación pública.
